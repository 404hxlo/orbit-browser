# 🪐 Orbit Browser

A fast, fun web browser for Windows — with spaces, split view, an ad blocker, a games arcade, a photo & video editor, and an AI sidebar built in.

## ⬇ Download

**[Download the latest version](../../releases/latest)** → run `Orbit-Setup-x.y.z.exe`.

Windows may say **"Windows protected your PC"** because Orbit isn't code-signed yet: click **More info → Run anyway**. Orbit then keeps itself up to date automatically.

## ✨ Features

| | |
|---|---|
| 🗂 **Spaces** | Separate sets of tabs (School, Gaming, Work…) |
| ◫ **Split view** | Two sites side by side |
| ⧉ **Pop-out tabs** | Drag a tab onto your second monitor and it gets its own window (videos keep playing) |
| 🕶 **Private windows** | No history, cookies or sign-ins kept after you close them |
| 📖 **Reading mode** | Just the article, in your font and size (F9) |
| 🖼 **Picture in picture** | Float any video above your other windows (Alt+P) |
| ⬇ **Easy switch** | Import bookmarks & history from Chrome, Edge, Brave, Vivaldi or Firefox |
| ⌘ **Command bar** | Ctrl+K to find any tab, bookmark, setting or game |
| 🛡 **Ad blocker** | Blocks ads and trackers out of the box |
| 🎬 **Orbit Studio** | Make thumbnails, memes, gaming clips and TikToks — made for beginners |
| 🎮 **Orbit Arcade** | 11 built-in games + 128 hand-picked web games |
| 🎵 **Music bar** | Play/pause/skip and volume for YouTube, Spotify and more |
| ⟲ **Rewind** | Scroll back through everything you looked at today |
| 📝 **Sticky notes** | Leave notes on any website |
| ◎ **Focus ring** | Block distracting sites for a set time |
| 🦎 **Chameleon** | The toolbar takes on each site's colors |
| ✦ **Orbit AI** | Claude in a sidebar (bring your own Anthropic API key) |

## 🔒 Privacy

Your bookmarks, history, Rewind snapshots and notes stay on your PC and are never uploaded. Besides the websites you visit, Orbit only connects to GitHub (to check for updates), downloads the ad blocker's filter lists, and talks to Anthropic if you use the AI sidebar with your own key.
